# 2026 Arctic Wolf Minibadges
This sections contains the instructions for all of Arctic Wolf's badges.  See each section for specific details.

## Main Badge
<img src="https://github.com/cyberm3n-org/SC_2026/blob/main/ref_images/AW26_Front.png" width="25%">

### Build List Items
| Ref | Value | Marking Color |
| --- | --- | --- |
| C1 | 0.01uF | Black |
| C2 | 10uF | Blue |
| D1, D2 | Blue LED | Blue |
| D3, D4, D5 | White LED | Yellow |
| R1 | 51K | Blue |
| R2 | 20K | Green |
| R3 | 56 | Pink |
| R4 | 30 | Orange |
| U1 | Timer | |

### Steps
Use your best judgement for best order of operation, as this will help in the "ease" of assembly --> List order is not necassarily the best order of operations
1. Solder 555 Timer
2. Solder Capacitors & Resistors
3. Solder LEDs
4. [OPTIONAL] Apply hot glue to difuse light
