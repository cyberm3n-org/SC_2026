## Nuka Cola

### Build List Items
| Ref | Value | Marking Color |
| --- | --- | --- |
| D1, D2 | White LED | Yellow |
| R1 | 30 | Orange |

### Steps
1. Solder LEDs
2. Solder R3 Resistor
3. [OPTIONAL] Apply hot glue to the back side to difuse light
