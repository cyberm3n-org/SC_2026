### Build List Items
| Ref | Value | Marking Color |
| D1, D2 | Yellow LED | Brown |
| R1 | 150 | Red |

### Steps
1. Solder LEDs
2. Solder Resistor
3. Bridge Jumper to obtain flashing or solid affect
4. [OPTIONAL] Apply hot glue to difuse light
